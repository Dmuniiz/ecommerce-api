# E-Commerce API

A production-oriented e-commerce API built with Java and Spring Boot.

Challenge link:`https://roadmap.sh/projects/ecommerce-api`.

## Overview

This project simulates a real-world e-commerce backend with authentication, catalog management, shopping cart, checkout, orders, payments, and production-readiness concerns such as testing, Docker, RabbitMQ, and monitoring.

The goal is not only to build CRUD endpoints, but to design a backend with clean architecture, good domain modeling, and practical engineering practices.

## Goals

- Build a secure REST API with JWT authentication
- Implement CRUD operations for core resources
- Model a realistic e-commerce domain
- Integrate with external payment services such as Stripe
- Apply SOLID principles and clean design patterns
- Add testing, observability, and containerized

There is a folder called "/docs" where you will have more details about the entire application and everything modular
